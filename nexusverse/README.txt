NEXUSVERSE-2K26 landing page
============================
index.html  -> the complete page (HTML + CSS + JS in one file, logos embedded).
              Just open it in a browser or upload it to any host (Vercel, Netlify, GitHub Pages).
assets/     -> original logo images, for reference or reuse.

Notes
- Uses Google Fonts (Cinzel, Poppins); needs internet for the fonts, otherwise falls back to serif/sans-serif.
- The "Registration starts soon" button is disabled. When registration opens, replace it in index.html with:
  <a href="YOUR_REGISTRATION_LINK">REGISTER NOW</a>
  (and style it like the existing .foot button in the CSS).
